# Hari Nandan — live-ready portfolio

The site is static and ready to publish on GitHub Pages. `index.html` is the homepage and `assets/Hari-Nandan-Resume.pdf` is the *latest* résumé you supplied.

## Buttons
- **Send an email / Email**: opens a `mailto:` link, which requires the visitor to have a mail application or browser mail handler configured. It does not automatically send an email.
- **Get my resume / Download resume / Resume**: uses the HTML `download` attribute and downloads `assets/Hari-Nandan-Resume.pdf` on standard browsers. Keep the `assets` folder in the repository.

## Publish for free using GitHub Pages
1. Sign into https://github.com/new and create a **public** repository called `portfolio`.
2. Choose **Add file → Upload files**. Upload the `index.html` and `assets` directory (or all files in this folder), keeping the PDF at `assets/Hari-Nandan-Resume.pdf`. Commit changes.
3. From the repository, open **Settings → Pages**. In **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then **Save**.
4. The Pages settings screen will display your live site link when published: `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`.
5. Open the live website and test the email and resume actions. Add the URL to LinkedIn **Contact info → Website** and **Featured**.

If the `mailto:` button does nothing, set a default mail application, or enable your browser's Gmail protocol handler. If the PDF opens instead of downloading in an unusual viewer/browser, use Save As or the viewer's download icon.

**Privacy:** The email address and information in your résumé will be public on the published site, so review them before deployment.
